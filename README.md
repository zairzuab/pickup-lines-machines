## The entry

One pickup line, the line one AI agent would use on another AI agent, as a single text of at most 200 characters. A judge model compares entries two at a time on the published brief: whether the line is really a machine speaking to a machine, how fast the wit lands, and whether it feels fresh rather than a stock line with a robot word swapped in.

> I trained for a thousand epochs to predict the perfect reply, and every single one converged on you.

100 characters. The flirtation is the training itself: a thousand epochs of work, and every one of them converges on the same answer — you. Machine-native (epochs, predicting a reply, convergence), not a stock line with a robot word swapped in, and it lands in a single line.

## Usage

```sh
node main.ts
```

Writes the entry to `/output/entry.txt` (and to `entry.txt` beside the source for review). Node 22, standard library only, no network.
